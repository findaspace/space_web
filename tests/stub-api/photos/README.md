# Local design-preview photos

These six images were downloaded from Unsplash (https://unsplash.com/) for local layout and upload testing. They are generic sample photographs, not verified photographs of the Ghana listings shown in the fixture data. Do not treat them as actual property inventory or deploy the fixture listings as public listings. Exact photographer/page attribution was not retained during retrieval; replace these with appropriately documented assets before using them beyond the local preview.

Production listing photos come from the API and should be supplied by authorised hosts. `DEMO_PHOTOS=true` enables these local fixture files; it is off by default in the test API.
